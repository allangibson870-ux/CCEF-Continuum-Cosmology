# A physical massless photon in CCEF — and does it inherit the A3 k⁴?

The decisive structural question. Worked from CCEF's axioms (single order parameter n,
A3 bilaplacian as fundamental UV regulator). The result is definitive and is a serious
structural finding for the particle/EM sector.

## Routes to a massless photon in CCEF
- The CP¹ gauge field a_μ=−i z†∂z is the natural emergent photon, but the A4-ordered
  vacuum Higgses it (m_γ≈1.2–1.8 CCEF). So a *massless* photon needs a different
  realization: a Goldstone of a residual/restored continuous symmetry, a deconfined-phase
  (un-Higgsed) U(1), or the synchronization-field phase mode (global U(1) θ_sync).
- All of these are, by CCEF's single-field axiom, **constructs of n**.

A3 enters the fundamental action as (A3/2)(∇²n)², acting on the whole order parameter.
Every propagating mode is a fluctuation/collective of n, so every mode inherits it:
- Goldstone/phase: n = n_vac + ê·θ ⇒ (∇²n)² = (∇²θ)² ⇒ a k⁴ term for θ.
- Matter tangent modes: ω²=A1k²+A3k⁴ (shown).
- Composite graviton: z=1 only up to ~k_UV; A3 enters at k_UV (shown via Π^TT).

**No Goldstone shift symmetry, gauge invariance, or custodial symmetry can shield a sector
from a *universal* term already present in the fundamental action.** Symmetries forbid
operators; they cannot remove a term that is there for every n-mode. Therefore:

**A physical massless photon in CCEF WILL inherit the A3 k⁴ term, with LV scale
k_UV=√(A1/A3) — the same as every other sector. It is NOT protected.**

- **(+) Virtue:** because *all* sectors share one dispersion ω²=A1k²+A3k⁴, there is
  **zero differential Lorentz violation** between any species, ever. GW170817 (c_gw=c_γ),

- **(−) Cost:** the surviving effect is a *universal, energy-dependent* speed. For a

The squeeze is broken only if the photon's dispersion is protected **independently of the
universal A3** — i.e. if the photon is NOT a generic n-construct but the **Goldstone of

favour.
- This is the *only* mechanism that could work, and **it is not realized in CCEF as
  formulated**: the emergent photon there is the CP¹/Berry construct (an n-bilinear), which
  inherits A3. Realizing the boost-Goldstone photon would require a different identification
